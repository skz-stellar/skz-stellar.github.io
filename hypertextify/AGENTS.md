# Repository instructions

- Use the name HyperTextify and the public path `/hypertextify/`.
- Keep conversion entirely in the browser. Preserve restrictive CSP policies,
  inert HTML parsing, isolated previews, and no-network/no-storage guarantees.
- Bundle dependencies and fonts locally; do not add runtime CDN resources.
- Do not add AI credits, co-authors, generated-by notices, or attribution trailers.
  Use the user's configured Git identity and preserve the commit-message hook.
